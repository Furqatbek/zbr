## Order Types & Flow Variations

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              ORDER TYPE VARIATIONS                                       │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ DELIVERY ORDER                                                                           │
│                                                                                          │
│   Consumer ──▶ Restaurant ──▶ Kitchen Prepares ──▶ Courier Assigned ──▶ Consumer        │
│                                                                                          │
│   States: CREATED → ACCEPTED → PREPARING → READY → PICKED_UP → IN_TRANSIT → DELIVERED  │
│                                                                        ↓                │
│                                                                   COMPLETED              │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ TAKEAWAY / PICKUP ORDER                                                                  │
│                                                                                          │
│   Consumer ──▶ Restaurant ──▶ Kitchen Prepares ──▶ Consumer Picks Up                    │
│                                                                                          │
│   States: CREATED → ACCEPTED → PREPARING → READY → COMPLETED                            │
│                                                                                          │
│   * No courier involved                                                                  │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ DINE-IN ORDER                                                                            │
│                                                                                          │
│   Consumer (at table) ──▶ Restaurant ──▶ Kitchen Prepares ──▶ Served at Table          │
│                                                                                          │
│   States: CREATED → ACCEPTED → PREPARING → READY → DELIVERED → COMPLETED                │
│                                                                                          │
│   * Table ID assigned, no courier                                                        │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
